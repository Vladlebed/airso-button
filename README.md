## Airso Button

**Airso Button** — это автономное устройство на базе ESP32 для управления игровой логикой и отображения ключевой статистики в страйкбольных сценариях.

Устройство предоставляет единый физический интерфейс (кнопку), через который игроки взаимодействуют с игровой механикой, в то время как вся логика и настройки полностью контролируются организаторами через веб-интерфейс.

---

## 🎮 Назначение

Airso Button используется как универсальный игровой модуль и может выполнять разные роли в зависимости от выбранного режима:

### 🔢 Increment (счётчик событий)
Каждое нажатие фиксирует событие (например, смерть игрока или команды) и увеличивает счётчик.  
Подходит для режимов с ограничением по количеству респаунов или для ведения статистики.

### 🔻 Decrement (ограниченные жизни)
Показывает оставшееся количество жизней. Каждое нажатие уменьшает значение.  
Используется в сценариях, где у команды или игрока есть ограниченное количество попыток.

### ⏱ Timer (таймер сценария)
Отсчитывает заданное время (например, захват точки, удержание позиции, разминирование).  
Может сопровождаться звуковыми сигналами.

---

## 🧩 Как используется в играх

Airso Button можно встроить практически в любой сценарий:

- 📍 **Точка захвата** — запуск или удержание таймера  
- 💣 **Бомба / разминирование** — активация обратного отсчёта  
- ❤️ **Ограниченные респауны** — учёт оставшихся жизней команды  
- ☠️ **Учёт смертей** — фиксация игровых событий  
- 🏁 **Контроль задач** — выполнение условий миссии через кнопку  

Устройство может выступать как:
- отдельная игровая точка  
- элемент распределённой системы (несколько устройств на поле)  
- инструмент игротехника для контроля процесса  

---

## ⚙️ Управление и настройка

- Все настройки выполняются через **веб-интерфейс**
- Игроки не имеют доступа к конфигурации
- Поддерживается гибкая настройка:
  - режима работы
  - начальных значений
  - параметров таймера
  - поведения устройства

> Не требуется перепрошивка для изменения параметров — всё настраивается "на лету".

## 🔊 Обратная связь

Airso Button даёт игрокам мгновенный фидбек:

- 📟 **Дисплей TM1637** — отображение текущего состояния (жизни, время, счёт)
- 🔔 **Зуммер** — звуковые сигналы при событиях
- 🔘 **Физическая кнопка** — основной интерфейс взаимодействия
